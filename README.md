# 🌞 Diantú

**Ordena tu día bajo el sol.**

Diantú es un planificador diario personal que organiza tus actividades en bloques de tiempo simples, sin la complejidad de un calendario tradicional.

---

## ✨ ¿Qué es Diantú?

En vez de un calendario lleno de funciones que casi nadie usa, Diantú se enfoca en una sola idea: **dividir tu día en bloques de tiempo**, cada uno con una hora de inicio, una hora de fin, una categoría con su color, y opcionalmente una alarma.

- 🕒 **Timeline diario** — visualiza tu día completo, bloque a bloque.
- 🎨 **Categorías por color** — clasifica tus actividades (trabajo, ejercicio, salud, descanso, etc.) de un vistazo.
- 🔔 **Alarmas** — marca los bloques que necesitan recordatorio.
- ✅ **Seguimiento simple** — marca bloques como completados a medida que avanza el día.
- 📥 **Inbox** — anota ideas o tareas sin horario definido y muévelas al timeline cuando corresponda.
- 🔒 **Privado por diseño** — cada usuario ve y edita únicamente sus propios datos.

## 🛠️ Stack técnico

| Capa | Tecnología |
|---|---|
| Backend | Django 6.0.7 (Python) |
| Base de datos | SQLite en desarrollo · PostgreSQL (Supabase) en producción |
| Frontend | HTML + CSS puro con variables + JavaScript vanilla |
| Autenticación | Sistema nativo de Django (usuario + contraseña) |
| Despliegue | Render (app) + Supabase (base de datos) |
| Íconos | Tabler Icons |

---

## 🎨 Identidad visual

Diantú usa una paleta en tonos verde esmeralda como color de marca, con tipografía sans-serif moderna. El logo representa un sol con 8 rayos rodeado por un anillo orbital, simbolizando tanto la marca como los bloques de tiempo del día.
